# v0.4.0

## Bug Fixes

- **Windows: 命令行窗口闪烁修复** — 移除前端每 1.4 秒轮询 `terminal_describe_processes` 的机制，为 `powershell.exe`、`taskkill.exe`、`command_exists()` 添加 `CREATE_NO_WINDOW` 标志，防止 Windows 上控制台窗口闪现
- **Agent 删除无反应修复** — `removeStation()` 和 `handleStationDeleteCleanupConfirm()` 添加 `catch` 块，Tauri IPC 错误不再被静默吞掉
- **终端强制关闭修复** — 关闭终端后回到空闲状态（显示"当前 Agent 尚未启动"和启动按钮），用自定义确认对话框替代 `window.confirm()`（解决 Windows WebView2 下同步对话框被抑制的问题）
- Git 面板多项修复与样式优化
- 终端恢复调度与工作区切换过渡优化
- 主题与对比度修复

## Features

- Git 面板：cherry-pick、revert、reset、merge、冲突解决、tag 管理、hunk 级暂存、multiline 编辑器、⌘R 刷新
- 飞书 QR 扫码连接流程
- 樱花夜（Sakura Night）暗色主题
- Dart/Flutter 等 11 种语言映射
- 新品牌应用图标

## CI

- Release workflow 自动从 git tag 同步版本号到所有配置文件，确保产物版本号一致
